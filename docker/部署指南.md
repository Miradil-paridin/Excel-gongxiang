# OnlyOffice Document Server 部署指南

## 一、前置要求

### 1. 系统要求
- **操作系统**: Linux / macOS / Windows (WSL2)
- **Docker**: 20.10 或更高版本
- **Docker Compose**: 2.0 或更高版本
- **内存**: 建议 4GB 或以上
- **磁盘空间**: 至少 2GB 可用空间

### 2. 安装 Docker

#### macOS
```bash
# 使用 Homebrew 安装
brew install docker docker-compose

# 或下载 Docker Desktop
# https://www.docker.com/products/docker-desktop
```

#### Ubuntu/Debian
```bash
# 安装 Docker
sudo apt-get update
sudo apt-get install docker.io docker-compose

# 启动 Docker 服务
sudo systemctl start docker
sudo systemctl enable docker
```

#### CentOS/RHEL
```bash
# 安装 Docker
sudo yum install docker docker-compose

# 启动 Docker 服务
sudo systemctl start docker
sudo systemctl enable docker
```

## 二、部署 OnlyOffice Document Server

### 1. 启动服务
```bash
cd docker

# 启动 OnlyOffice
docker-compose up -d

# 查看日志
docker-compose logs -f
```

### 2. 验证部署
```bash
# 检查容器状态
docker-compose ps

# 应该看到 onlyoffice-document-server 状态为 Up

# 访问健康检查接口
curl http://localhost:8081/healthcheck

# 正常应返回: true
```

### 3. 访问 OnlyOffice
- **服务地址**: `http://localhost:8081`
- **健康检查**: `http://localhost:8081/healthcheck`

---

## 三、配置说明

### 1. 端口配置
```yaml
ports:
  - "8081:80"  # 将容器的 80 端口映射到主机的 8081 端口
```

**修改端口** (如需使用其他端口):
```yaml
ports:
  - "8082:80"  # 使用 8082 端口
```

### 2. 数据持久化
```yaml
volumes:
  - ./onlyoffice/data:/var/www/onlyoffice/Data     # 文档数据
  - ./onlyoffice/logs:/var/log/onlyoffice          # 日志文件
  - ./onlyoffice/fonts:/usr/share/fonts           # 自定义字体
```

**数据目录说明**:
- `onlyoffice/data` - 存储临时文档和缓存
- `onlyoffice/logs` - OnlyOffice 运行日志
- `onlyoffice/fonts` - 可放置自定义字体文件

### 3. JWT 认证 (生产环境必需)

#### 启用 JWT
编辑 `docker-compose.yml`:
```yaml
environment:
  - JWT_ENABLED=true
  - JWT_SECRET=your-secure-secret-key-here
  - JWT_HEADER=AuthorizationJWT
```

#### 后端配置
在 `backend/docshare/settings.py` 中配置相同的密钥:
```python
ONLYOFFICE_JWT_ENABLED = True
ONLYOFFICE_JWT_SECRET = 'your-secure-secret-key-here'
ONLYOFFICE_JWT_HEADER = 'AuthorizationJWT'
```

## 四、常用命令

### 1. 管理服务
```bash
# 启动服务
docker-compose up -d

# 停止服务
docker-compose down

# 重启服务
docker-compose restart

# 查看日志
docker-compose logs -f

# 查看容器状态
docker-compose ps
```

### 2. 更新版本
```bash
# 拉取最新镜像
docker-compose pull

# 重新创建容器
docker-compose up -d --force-recreate
```

### 3. 数据备份
```bash
# 备份数据目录
tar -czf onlyoffice-backup-$(date +%Y%m%d).tar.gz onlyoffice/

# 恢复备份
tar -xzf onlyoffice-backup-20260214.tar.gz
```

## 五、故障排查

### 1. 容器无法启动
```bash
# 查看详细日志
docker-compose logs onlyoffice-document-server

# 检查端口占用
lsof -i :8081

# 释放端口后重试
```

### 2. 健康检查失败
```bash
# 等待服务完全启动 (首次启动需要 2-3 分钟)
sleep 180
curl http://localhost:8081/healthcheck

# 检查日志
docker-compose logs -f
```

### 3. 内存不足
```bash
# 查看内存使用
docker stats

# 增加内存限制
# 编辑 docker-compose.yml，添加:
mem_limit: 2g
```

### 4. 文件上传失败
```bash
# 检查磁盘空间
df -h

# 清理旧数据
docker-compose down
rm -rf onlyoffice/data/*
docker-compose up -d
```

## 六、生产环境部署建议

### 1. 使用域名和 HTTPS
```nginx
# Nginx 配置示例
server {
    listen 443 ssl;
    server_name office.yourdomain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 2. 启用 JWT 认证
- 修改 `docker-compose.yml` 启用 JWT
- 使用强密码作为 JWT_SECRET
- 定期更换密钥

### 3. 配置防火墙
```bash
# 只允许内网访问
sudo ufw allow from 192.168.0.0/16 to any port 8081
```

### 4. 监控和告警
- 配置日志轮转
- 监控磁盘空间
- 监控内存使用
- 设置告警通知

## 七、性能优化

### 1. 内存优化
```yaml
environment:
  - AMQP_URI=amqp://guest:guest@localhost:5672
mem_limit: 4g
```

### 2. 使用 Redis 缓存
```yaml
services:
  redis:
    image: redis:latest
    ports:
      - "6379:6379"

  onlyoffice-document-server:
    # ... 其他配置
    depends_on:
      - redis
```

### 3. 负载均衡 (多实例)
```yaml
services:
  onlyoffice-1:
    image: onlyoffice/documentserver:latest
    ports:
      - "8081:80"

  onlyoffice-2:
    image: onlyoffice/documentserver:latest
    ports:
      - "8082:80"
```
