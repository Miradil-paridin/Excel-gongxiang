### 1. Share 模型 (已完成 ✅)

**核心特性**:
- ✅ 支持文档和文件分享
- ✅ 两种权限级别 (只读/可编辑)
- ✅ 过期时间控制
- ✅ 分享留言功能
- ✅ 数据库约束确保数据一致性

### 2. Share API 接口 (已完成设计 ✅)

```
POST   /api/shares/                    # 创建分享
GET    /api/shares/                    # 获取我的分享记录
GET    /api/shares/my-shares/          # 我分享给别人的
GET    /api/shares/shared-with-me/     # 别人分享给我的
GET    /api/shares/{id}/               # 分享详情
PATCH  /api/shares/{id}/               # 更新分享权限
DELETE /api/shares/{id}/               # 取消分享
```

### 3. 权限控制 (已完成设计 ✅)

**三种权限**:
- `owner` - 所有者 (完全控制)
- `write` - 可编辑 (编辑权限)
- `read` - 只读 (查看权限)

**权限判断逻辑**:
```python
# 后端
if user == document.creator:
    permission = 'owner'
elif share and share.permission == 'write':
    permission = 'write'
elif share:
    permission = 'read'
else:
    permission = None  # 无权限
```

```
3. 点击"取消"按钮
4. 后端删除/禁用 Share 记录
5. 用户B不再能看到该文档
```

## 🎓 核心技术要点

### 1. 数据库设计
```python
# 使用 CheckConstraint 确保数据完整性
constraints = [
    models.CheckConstraint(
        check=Q(document__isnull=False) | Q(file__isnull=False),
        name='share_document_or_file_not_null'
    )
]
```

### 2. 权限验证
```python
# 只有分享者才能修改分享
if instance.sharer != request.user:
    return Response({'message': '只有分享者才能修改分享'}, status=403)
```

### 3. 联合查询
```python
# 查询用户自己的 + 被分享的文档
own_docs = Document.objects.filter(creator=user)
shared_docs = Document.objects.filter(shares__sharee=user)
result = (own_docs | shared_docs).distinct()
```

### 4. 前端权限显示
```vue
<!-- 根据权限显示不同操作按钮 -->
<template v-if="permission === 'owner'">
  <el-button @click="edit">编辑</el-button>
  <el-button @click="share">分享</el-button>
</template>
<template v-else-if="permission === 'write'">
  <el-button @click="edit">编辑</el-button>
  <el-button disabled>分享</el-button>
</template>
<template v-else>
  <el-button disabled>编辑</el-button>
</template>
```
