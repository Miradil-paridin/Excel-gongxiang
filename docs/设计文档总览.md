## 🛠️ 技术选型

### 后端
- **语言**: Python 3.11+
- **框架**: Django 5.0 + DRF
- **数据库**: PostgreSQL 15
- **缓存**: Redis
- **实时通信**: Django Channels (WebSocket)
- **文件存储**: 本地磁盘

### 前端
- **框架**: Vue 3 + TypeScript
- **构建**: Vite
- **UI库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP**: Axios
- **编辑器**:
  - 富文本: Tiptap
  - 表格: Luckysheet

### 部署
- **Web服务器**: Nginx
- **应用服务器**: Gunicorn
- **进程管理**: Supervisor
- **容器**: Docker (可选)
