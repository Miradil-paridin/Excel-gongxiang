## 🌐 局域网部署配置

### 1. 修改Django配置

编辑 `backend/docshare/settings.py`:

```python
# 修改ALLOWED_HOSTS
ALLOWED_HOSTS = [
    'localhost',
    '127.0.0.1',
    # 添加局域网IP地址 (示例)
    '192.168.1.100',  # 替换为你的实际局域网IP
    '192.168.0.100',  # 可以添加多个IP
]

# 静态文件配置
STATIC_URL = '/static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'

MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'

# CORS配置 (允许局域网访问)
CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",
    "http://127.0.0.1:3000",
    "http://192.168.1.100:3000",  # 替换为你的局域网IP
]

CORS_ALLOW_CREDENTIALS = True
```

### 2. 获取局域网IP地址

在macOS/Linux:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

在Windows:
```cmd
ipconfig
```

### 3. 启动服务器 (局域网模式)

**后端**:
```bash
source venv/bin/activate
cd backend
python manage.py collectstatic --noinput  # 收集静态文件
python manage.py runserver 0.0.0.0:8000
```

**前端**:
```bash
cd frontend
# 修改 vite.config.ts (如果需要)
npm run dev -- --host 0.0.0.0 --port 3000
```

### 4. 其他设备访问

在局域网内的其他设备浏览器中访问:
- **前端**: `http://<你的IP>:3000`
  - 示例: `http://192.168.1.100:3000`
- **后端API**: `http://<你的IP>:8000/api/`

### 5. 防火墙配置

**macOS**:
```bash
# 允许8000和3000端口
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /path/to/python
```

**Windows**:
- 打开"控制面板" -> "Windows Defender 防火墙" -> "高级设置"
- 添加入站规则，允许端口 8000 和 3000

**Linux** (Ubuntu):
```bash
sudo ufw allow 8000/tcp
sudo ufw allow 3000/tcp
```

## 🚀 生产环境部署建议

### 1. 使用生产级Web服务器

**推荐配置**:
- **Web服务器**: Nginx 或 Apache
- **WSGI服务器**: Gunicorn 或 uWSGI
- **静态文件**: Nginx 直接处理
- **媒体文件**: Nginx 直接处理

### 2. 数据库配置

**开发环境**: SQLite ✅
**生产环境**: PostgreSQL 或 MySQL

### 3. 部署脚本示例

```bash
#!/bin/bash
# deploy.sh

# 停止旧服务
pkill -f gunicorn

# 激活虚拟环境
source venv/bin/activate

# 进入项目目录
cd backend

# 收集静态文件
python manage.py collectstatic --noinput

# 迁移数据库
python manage.py migrate

# 启动Gunicorn
gunicorn docshare.wsgi:application \
  --bind 0.0.0.0:8000 \
  --workers 4 \
  --timeout 120 \
  --access-logfile logs/access.log \
  --error-logfile logs/error.log \
  --daemon
```

### 4. Nginx配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 静态文件
    location /static/ {
        alias /path/to/staticfiles/;
    }

    # 媒体文件
    location /media/ {
        alias /path/to/media/;
    }

    # 后端API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 前端
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
