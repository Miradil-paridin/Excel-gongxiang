### 一、后端开发 (Django)

#### 1. Document 模型 (documents/models.py)
**字段**:
- `title` - 文档标题
- `type` - 文档类型 (doc富文本 / sheet表格)
- `content` - 文档内容
- `creator` - 创建者 (外键关联 User)
- `created_at` - 创建时间
- `updated_at` - 更新时间
- `version` - 版本号 (自动递增)
- `is_deleted` - 软删除标记
- `deleted_at` - 删除时间

**特性**:
- ✅ 支持富文本文档和表格文档两种类型
- ✅ 版本号自动递增
- ✅ 软删除机制
- ✅ 数据库索引优化

---

#### 2. File 模型 (files/models.py)
**字段**:
- `name` - 存储文件名
- `original_name` - 原始文件名
- `file` - 文件字段
- `size` - 文件大小(字节)
- `mime_type` - MIME类型
- `uploader` - 上传者 (外键关联 User)
- `created_at` - 上传时间
- `is_deleted` - 软删除标记

**特性**:
- ✅ 文件上传路径动态生成 (uploads/username/year/month/)
- ✅ 支持的文件类型: PDF/Word/Excel/PPT/图片/压缩包等
- ✅ 文件大小和MIME类型自动计算
- ✅ 删除时自动清理物理文件
- ✅ 文件类型分类 (image/document/spreadsheet等)

- ✅ `POST /api/documents/` - 创建文档
- ✅ `GET /api/documents/{id}/` - 获取文档详情

### 三、前后端联调

#### 后端 API 测试

##### 1. 创建文档
```bash
curl -X POST http://127.0.0.1:8000/api/documents/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试文档",
    "type": "doc"
  }'
```

##### 2. 获取文档列表
```bash
curl -X GET "http://127.0.0.1:8000/api/documents/?type=doc&page=1&page_size=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

##### 3. 上传文件
```bash
curl -X POST http://127.0.0.1:8000/api/files/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@/path/to/test.pdf"
```

##### 4. 下载文件
```bash
curl -X GET http://127.0.0.1:8000/api/files/1/download/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -o downloaded.pdf
```
