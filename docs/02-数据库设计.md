## 数据库表详细设计

### 1. 用户表 (User)

```sql
-- Django内置User模型扩展
CREATE TABLE auth_user (
    id SERIAL PRIMARY KEY,
    username VARCHAR(150) UNIQUE NOT NULL,
    email VARCHAR(254) UNIQUE NOT NULL,
    password VARCHAR(128) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    is_staff BOOLEAN DEFAULT FALSE,  -- 管理员
    is_superuser BOOLEAN DEFAULT FALSE,
    date_joined TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP NULL,
    first_name VARCHAR(150) DEFAULT '',
    last_name VARCHAR(150) DEFAULT ''
);

-- 用户扩展信息表
CREATE TABLE user_profile (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES auth_user(id) ON DELETE CASCADE UNIQUE,
    avatar VARCHAR(500) DEFAULT '',  -- 头像路径
    department VARCHAR(100) DEFAULT '',  -- 部门
    phone VARCHAR(20) DEFAULT '',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2. 文档表 (Document)

```sql
CREATE TABLE document (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL DEFAULT '未命名文档',
    type VARCHAR(20) NOT NULL,  -- 'doc' (富文本), 'sheet' (表格)
    content TEXT,  -- JSON格式存储文档内容
    creator_id INTEGER REFERENCES auth_user(id) ON DELETE CASCADE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    version INTEGER DEFAULT 1,  -- 当前版本号
    is_deleted BOOLEAN DEFAULT FALSE,
    deleted_at TIMESTAMP NULL,
    is_public BOOLEAN DEFAULT FALSE,  -- 是否公开（所有人可见）

    INDEX idx_creator (creator_id),
    INDEX idx_type (type),
    INDEX idx_deleted (is_deleted),
    INDEX idx_updated_at (updated_at)
);
```

### 3. 文件表 (File)

```sql
CREATE TABLE file (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,  -- 存储文件名（含UUID）
    original_name VARCHAR(255) NOT NULL,  -- 原始文件名
    path VARCHAR(500) NOT NULL,  -- 存储路径 /data/uploads/xxx
    size BIGINT NOT NULL,  -- 文件大小（字节）
    mime_type VARCHAR(100),  -- MIME类型
    md5_hash CHAR(32),  -- 文件MD5哈希（用于去重）
    uploader_id INTEGER REFERENCES auth_user(id) ON DELETE CASCADE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    thumbnail_path VARCHAR(500),  -- 缩略图路径（图片、PDF等）
    is_deleted BOOLEAN DEFAULT FALSE,
    deleted_at TIMESTAMP NULL,

    INDEX idx_uploader (uploader_id),
    INDEX idx_md5 (md5_hash),
    INDEX idx_deleted (is_deleted),
    INDEX idx_created_at (created_at)
);
```

### 4. 分享表 (Share)

```sql
CREATE TABLE share (
    id SERIAL PRIMARY KEY,
    document_id INTEGER REFERENCES document(id) ON DELETE CASCADE NULL,
    file_id INTEGER REFERENCES file(id) ON DELETE CASCADE NULL,
    sharer_id INTEGER REFERENCES auth_user(id) ON DELETE CASCADE NOT NULL,  -- 分享者
    sharee_id INTEGER REFERENCES auth_user(id) ON DELETE CASCADE NOT NULL,  -- 被分享者
    permission VARCHAR(20) NOT NULL DEFAULT 'read',  -- 'read' 或 'write'
    shared_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    expired_at TIMESTAMP NULL,  -- 过期时间，NULL表示永久有效
    is_active BOOLEAN DEFAULT TRUE,
    message TEXT DEFAULT '',  -- 分享留言

    CHECK ((document_id IS NOT NULL AND file_id IS NULL) OR
           (document_id IS NULL AND file_id IS NOT NULL)),
    INDEX idx_sharer (sharer_id),
    INDEX idx_sharee (sharee_id),
    INDEX idx_document (document_id),
    INDEX idx_file (file_id),
    INDEX idx_active (is_active)
);
```

### 5. 文档版本表 (DocumentVersion)

```sql
CREATE TABLE document_version (
    id SERIAL PRIMARY KEY,
    document_id INTEGER REFERENCES document(id) ON DELETE CASCADE NOT NULL,
    version_number INTEGER NOT NULL,  -- 版本号
    content TEXT NOT NULL,  -- 版本内容
    changed_by INTEGER REFERENCES auth_user(id) ON DELETE SET NULL NULL,
    changed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    change_summary VARCHAR(500) DEFAULT '',  -- 变更摘要

    UNIQUE (document_id, version_number),
    INDEX idx_document (document_id),
    INDEX idx_version (version_number)
);
```

### 6. 协同操作日志表 (CollaborationLog)

```sql
CREATE TABLE collaboration_log (
    id SERIAL PRIMARY KEY,
    document_id INTEGER REFERENCES document(id) ON DELETE CASCADE NOT NULL,
    user_id INTEGER REFERENCES auth_user(id) ON DELETE SET NULL NULL,
    operation_type VARCHAR(50) NOT NULL,  -- 'insert', 'delete', 'format' 等
    operation_data JSONB NOT NULL,  -- 操作数据（OT/CRDT算法）
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    client_id VARCHAR(100),  -- 客户端唯一标识

    INDEX idx_document (document_id),
    INDEX idx_timestamp (timestamp),
    INDEX idx_user (user_id)
);
```

### 7. 用户操作日志表 (UserActivityLog)

```sql
CREATE TABLE user_activity_log (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES auth_user(id) ON DELETE SET NULL NULL,
    action VARCHAR(50) NOT NULL,  -- 'create', 'update', 'delete', 'share', 'login' 等
    target_type VARCHAR(50),  -- 'document', 'file', 'share'
    target_id INTEGER,  -- 目标对象ID
    ip_address INET,  -- IP地址
    user_agent TEXT,  -- User-Agent
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_user (user_id),
    INDEX idx_action (action),
    INDEX idx_created_at (created_at),
    INDEX idx_target (target_type, target_id)
);
```

## 索引优化建议

1. **查询优化索引**:
   - `document(creator_id, is_deleted, updated_at)` - 按用户查询文档列表
   - `file(uploader_id, is_deleted, created_at)` - 按用户查询文件列表
   - `share(sharee_id, is_active)` - 查询"与我分享"的文档
   - `document_version(document_id, version_number DESC)` - 查询最新版本

2. **全文搜索索引** (PostgreSQL):
   ```sql
   CREATE INDEX idx_document_title_search ON document USING GIN (to_tsvector('chinese', title));
   CREATE INDEX idx_file_name_search ON file USING GIN (to_tsvector('chinese', original_name));
   ```
