## 🔒 权限控制

### 后端权限
所有管理后台API都使用 `IsAdminUser` 权限类:

```python
class IsAdminUser(permissions.BasePermission):
    """只允许管理员访问"""
    def has_permission(self, request, view):
        return request.user and request.user.is_staff
```

### 前端权限 (待集成)
需要在主路由中添加 `requiresAdmin: true` 元信息:

```javascript
{
  path: '/admin',
  meta: { requiresAdmin: true }
}
```

并在路由守卫中检查:
```javascript
router.beforeEach((to, from, next) => {
  const user = JSON.parse(localStorage.getItem('user') || '{}')
  if (to.meta.requiresAdmin && !user.is_staff) {
    ElMessage.error('无权访问管理后台')
    next('/dashboard')
  }
})
```

### 2. 趋势数据分析
```python
# 最近7天的用户增长趋势
for i in range(7):
    date = today - timedelta(days=6-i)
    date_start = date.replace(hour=0, minute=0, second=0)
    date_end = date.replace(hour=23, minute=59, second=59)

    new_users = User.objects.filter(
        date_joined__gte=date_start,
        date_joined__lte=date_end
    ).count()
```

```python
# 文档筛选
queryset = Document.objects.all()
if creator_id:
    queryset = queryset.filter(creator_id=creator_id)
if doc_type:
    queryset = queryset.filter(type=doc_type)

    queryset = queryset.filter(is_deleted=(is_deleted == 'true'))
```
