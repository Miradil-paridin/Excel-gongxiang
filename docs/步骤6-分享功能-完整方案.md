### 4. 文档/文件序列化器扩展 (待完成 ⏳)

**文件**: `backend/documents/serializers.py`

```python
class DocumentSerializer(serializers.ModelSerializer):
    # ... 原有字段

    # 新增分享相关字段
    is_shared = serializers.SerializerMethodField()  # 是否被分享
    share_count = serializers.SerializerMethodField()  # 分享次数
    current_permission = serializers.SerializerMethodField()  # 当前用户权限

    def get_is_shared(self, obj):
        return obj.shares.filter(is_active=True).exists()

    def get_share_count(self, obj):
        return obj.shares.filter(is_active=True).count()

    def get_current_permission(self, obj):
        request = self.context.get('request')
        if not request:
            return None

        # 如果是所有者
        if obj.creator == request.user:
            return 'owner'

        # 查询分享权限
        share = obj.shares.filter(
            sharee=request.user,
            is_active=True
        ).first()

        if share:
            return share.permission

        return None
```

### 5. 文档/文件视图扩展 (待完成 ⏳)

**文件**: `backend/documents/views.py`

```python
class DocumentListCreateView(generics.ListCreateAPIView):
    def get_queryset(self):
        user = self.request.user

        # 获取用户自己的文档 + 被分享的文档
        own_docs = Document.objects.filter(creator=user, is_deleted=False)

        shared_docs = Document.objects.filter(
            shares__sharee=user,
            shares__is_active=True,
            is_deleted=False
        ).distinct()

        return (own_docs | shared_docs).order_by('-updated_at')
```

### 1. 查询被分享的文档
```python
# 高效查询
shares = Share.objects.filter(
    sharee=user,
    is_active=True,
    document__isnull=False
).select_related(
    'document',
    'document__creator',
    'sharer'
).prefetch_related(
    'document__shares'
)

documents = [share.document for share in shares]
```

### 2. 统计分享次数

```python
from django.db.models import Count

document = Document.objects.annotate(
    share_count=Count('shares', filter=models.Q(shares__is_active=True))
).get(id=1)
```

## 🎯 权限控制策略

### 后端权限
```python
# 文档访问权限检查
def can_access_document(user, document):
    # 1. 所有者
    if document.creator == user:
        return True

    # 2. 被分享者
    share = Share.objects.filter(
        document=document,
        sharee=user,
        is_active=True
    ).first()

    if share and not share.is_expired():
        return True

    return False

# 文档编辑权限检查
def can_edit_document(user, document):
    # 1. 所有者
    if document.creator == user:
        return True

    # 2. 被分享且有写权限
    share = Share.objects.filter(
        document=document,
        sharee=user,
        is_active=True,
        permission='write'
    ).first()

    return share and not share.is_expired()
```

### 前端权限显示
```vue
<!-- 根据权限显示不同操作 -->
<template v-if="permission === 'owner'">
  <el-button @click="edit">编辑</el-button>
  <el-button @click="share">分享</el-button>
  <el-button @click="delete">删除</el-button>
</template>

<template v-else-if="permission === 'write'">
  <el-button @click="edit">编辑</el-button>
  <el-button disabled>分享</el-button>
  <el-button disabled>删除</el-button>
</template>

<template v-else-if="permission === 'read'">
  <el-button disabled>编辑</el-button>
  <el-button disabled>分享</el-button>
  <el-button disabled>删除</el-button>
</template>
```
