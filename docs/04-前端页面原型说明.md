# 04-前端页面原型说明

## 页面结构概览

```
┌─────────────────────────────────────────────────────────────────────┐
│                           前端应用 (Vue 3)                           │
└─────────────────────────────────────────────────────────────────────┘

路由结构:
/
├── /login                    # 登录页
├── /register                 # 注册页
├── /dashboard                # 首页/仪表盘 (需登录)
│   ├── /dashboard/documents  # 文档列表
│   ├── /dashboard/files      # 文件列表
│   └── /dashboard/shared     # 与我分享
├── /editor/:id               # 文档编辑器页
├── /file-preview/:id         # 文件预览页
└── /admin                    # 管理后台 (需管理员权限)
    ├── /admin/dashboard      # 管理仪表盘
    ├── /admin/users          # 用户管理
    ├── /admin/documents      # 文档管理
    ├── /admin/files          # 文件管理
    └── /admin/settings       # 系统设置
```

## 移动端适配

所有页面需支持响应式布局，在移动端自动调整为:
- 顶部导航栏折叠为汉堡菜单
- 侧边栏变为底部导航或抽屉式菜单
- 表格视图转为卡片视图
- 编辑器工具栏简化为浮动按钮

## 交互细节

1. **自动保存**: 文档编辑时，每30秒自动保存一次
2. **实时协作**: 多人编辑时，光标和操作实时显示
3. **权限控制**: 根据用户权限显示/隐藏相应功能
4. **加载状态**: 所有异步操作显示加载动画
5. **错误提示**: 统一的错误提示组件
6. **确认对话框**: 删除、退出等危险操作需二次确认
