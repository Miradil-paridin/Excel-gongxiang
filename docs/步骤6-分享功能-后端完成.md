```
3. 被分享文档显示权限标识 (只读/可编辑)
```

```
1. 用户A进入"我的分享"页面
2. 显示所有分享出去的记录

```

## 📊 数据库设计

### Share 表结构
```python
class Share(models.Model):
    document = ForeignKey(Document)      # 关联文档
    file = ForeignKey(File)              # 关联文件
    sharer = ForeignKey(User)            # 分享者
    sharee = ForeignKey(User)            # 被分享者
    permission = CharField('read/write') # 权限
    shared_at = DateTimeField()          # 分享时间
    expired_at = DateTimeField()         # 过期时间
    is_active = BooleanField()           # 是否激活
    message = TextField()                # 留言
```

### 关系设计
- `Document.shares` - 文档的所有分享记录
- `File.shares` - 文件的所有分享记录
- `User.shared_from` - 用户分享出去的记录
- `User.shared_to` - 分享给用户的记录

## 🎯 权限控制逻辑

### 后端权限判断
```python
# 文档/文件访问权限
def get_permission(self, obj):
    request = self.context.get('request')

    # 1. 所有者
    if request.user == obj.creator/uploader:
        return 'owner'

    # 2. 查询分享权限
    share = Share.objects.filter(
        document/file=obj,
        sharee=request.user,
        is_active=True
    ).first()

    if share:
        return share.permission  # 'read' 或 'write'

    return None  # 无权限
```
