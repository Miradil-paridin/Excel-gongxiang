# 步骤3：用户认证模块 - 开发完成 ✅

## 已完成的工作

### 后端 (Django + DRF + SQLite + JWT)

#### 1. 项目初始化
- ✅ 创建 Django 4.2.10 项目
- ✅ 配置 SQLite3 数据库
- ✅ 集成 Django REST Framework
- ✅ 配置 JWT Token 认证
- ✅ 配置 CORS 跨域支持

#### 2. 用户认证模块
- ✅ 用户注册接口 (`POST /api/auth/register/`)
- ✅ 用户登录接口 (`POST /api/auth/login/`)
- ✅ 获取用户信息接口 (`GET /api/auth/me/`)
- ✅ 修改密码接口 (`POST /api/auth/change-password/`)

#### 3. 序列化器
- ✅ `UserSerializer` - 用户信息
- ✅ `UserRegisterSerializer` - 带验证的注册序列化器
- ✅ `UserLoginSerializer` - 登录验证
- ✅ `ChangePasswordSerializer` - 密码修改验证

#### 4. 自定义权限类
- ✅ `IsAdminOrReadOnly` - 管理员可写
- ✅ `IsOwnerOrAdmin` - 所有者或管理员
- ✅ `IsAdminUser` - 仅管理员

#### 5. API 特性
- ✅ 密码加密存储
- ✅ 密码强度验证
- ✅ 用户名/邮箱唯一性检查
- ✅ 两次密码一致性验证
- ✅ Token 有效期 12 小时
- ✅ 统一响应格式 `{code, message, data}`

## 🚀 快速启动

### 启动后端

```bash
cd backend
source ../venv/bin/activate
python manage.py runserver
```

服务地址: **http://127.0.0.1:8000**

### 启动前端

```bash
cd frontend
npm run dev
```

服务地址: **http://localhost:3000**

---

## 🔧 首次使用

### 1. 创建管理员账户

```bash
cd backend
source ../venv/bin/activate
python manage.py createsuperuser
```

### 2. 访问系统

- 前端: **http://localhost:3000**
- 后端 API: **http://127.0.0.1:8000/api/**
- Django Admin: **http://127.0.0.1:8000/admin/**
