## 局域网访问配置

### 1. 获取本机局域网IP

**macOS/Linux**:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
# 或
ipconfig getifaddr en0
```

**Windows**:
```cmd
ipconfig
```

假设获取到的IP是: `192.168.1.100`

### 2. 修改Django配置

`backend/docshare/settings.py` 已配置:
```python
ALLOWED_HOSTS = [
    'localhost',
    '127.0.0.1',
    '0.0.0.0',
]
```

### 3. 修改前端API地址

创建/修改 `frontend/.env.local`:
```env
VITE_API_BASE_URL=http://192.168.1.100:8000/api
```

或修改 `frontend/vite.config.ts`:
```typescript
export default defineConfig({
  server: {
    host: '0.0.0.0',
    port: 3000,
    proxy: {
      '/api': {
        target: 'http://192.168.1.100:8000',
        changeOrigin: true
      }
    }
  }
})
```

### 4. 启动服务

**后端**:
```bash
cd backend
python manage.py runserver 0.0.0.0:8000
```

**前端**:
```bash
cd frontend
npm run dev -- --host 0.0.0.0 --port 3000
```

### 5. 局域网访问

在局域网内其他设备的浏览器中访问:
```
http://192.168.1.100:3000
```

## 防火墙配置

### macOS

**允许8000端口 (后端)**:
```bash
# macOS防火墙通常会自动询问是否允许Python访问网络
# 如果没有弹出提示，可以手动配置:

# 打开"系统设置" -> "网络" -> "防火墙" -> "选项"
# 添加Python应用到允许列表
```

**允许3000端口 (前端)**:
```bash
# Vite开发服务器通常不需要额外配置
```

**允许8081端口 (OnlyOffice)**:
```bash
# Docker会自动配置端口映射
```

### Windows

1. 打开"控制面板" -> "Windows Defender 防火墙"
2. 点击"高级设置"
3. 选择"入站规则" -> "新建规则"
4. 选择"端口" -> "TCP" -> 输入端口号: `8000,3000,8081`
5. 选择"允许连接"
6. 勾选所有配置文件 (域、专用、公用)
7. 命名规则: "Excel共享系统"
8. 点击"完成"

### Linux (Ubuntu)

```bash
# 安装ufw (如果未安装)
sudo apt install ufw

# 允许SSH (重要!)
sudo ufw allow 22/tcp

# 允许系统端口
sudo ufw allow 8000/tcp
sudo ufw allow 3000/tcp
sudo ufw allow 8081/tcp

# 启用防火墙
sudo ufw enable

# 查看状态
sudo ufw status
```

## 常见问题

### 1. 端口被占用

**问题**: `Error: That port is already in use`

**解决**:
```bash
# macOS/Linux
lsof -i :8000
kill -9 <PID>

# Windows
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

或修改端口号:
```bash
python manage.py runserver 0.0.0.0:8001
```

### 2. 无法访问局域网IP

**检查项**:
- ✅ 防火墙是否允许端口访问
- ✅ IP地址是否正确
- ✅ 服务是否使用 `0.0.0.0` 启动
- ✅ 设备是否在同一局域网

**测试**:
```bash
# 在本机测试
curl http://192.168.1.100:8000/api/auth/user/

# 在其他设备测试
ping 192.168.1.100
telnet 192.168.1.100 8000
```

### 3. OnlyOffice无法访问

**检查**:
```bash
# 检查容器状态
docker-compose ps

# 查看日志
docker-compose logs

# 重启服务
docker-compose restart
```

**常见原因**:
- 端口8081被占用
- Docker未启动
- 首次启动需要2-3分钟

### 4. 数据库错误

**初始化数据库**:
```bash
cd backend
python manage.py migrate
```

**重置数据库**:
```bash
# 备份数据
cp db.sqlite3 db.sqlite3.backup

# 删除数据库
rm db.sqlite3

# 重新初始化
python manage.py migrate
python create_test_users.py
```

### 5. 前端无法连接后端

**检查**:
1. 后端服务是否启动
2. `VITE_API_BASE_URL` 配置是否正确
3. 浏览器控制台是否有CORS错误

**解决**:
```bash
# 前端开发服务器
npm run dev -- --host 0.0.0.0 --port 3000

# 检查环境变量
cat .env.local
```

## 完整启动脚本

创建 `start.sh`:
```bash
#!/bin/bash

echo "🚀 Excel共享系统 - 启动脚本"
echo "================================"

# 激活虚拟环境
echo "1. 激活虚拟环境..."
source venv/bin/activate

# 启动后端
echo "2. 启动后端服务..."
cd backend
python manage.py migrate
python manage.py runserver 0.0.0.0:8000 &
BACKEND_PID=$!

# 等待后端启动
sleep 3

# 启动前端
echo "3. 启动前端服务..."
cd ../frontend
npm run dev -- --host 0.0.0.0 --port 3000 &
FRONTEND_PID=$!

echo "================================"
echo "✅ 服务已启动!"
echo ""
echo "后端: http://localhost:8000"
echo "前端: http://localhost:3000"
echo ""
echo "按 Ctrl+C 停止服务"
echo "================================"

# 等待进程结束
wait $BACKEND_PID $FRONTEND_PID
```

使用:
```bash
chmod +x start.sh
./start.sh
```

## 性能优化建议

### 1. 生产环境部署

使用Gunicorn替代开发服务器:
```bash
pip install gunicorn

cd backend
gunicorn docshare.wsgi:application \
  --bind 0.0.0.0:8000 \
  --workers 4 \
  --timeout 120
```

### 2. 静态文件

收集静态文件:
```bash
python manage.py collectstatic --noinput
```

### 3. 数据库优化

添加索引:
```python
# 已在models中配置
indexes = [
    models.Index(fields=['creator', '-updated_at']),
    models.Index(fields=['is_deleted']),
]
```
